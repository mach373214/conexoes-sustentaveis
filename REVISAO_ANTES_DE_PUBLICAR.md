# Revisão humana antes de publicar

A 04E.1 prepara tecnicamente os arquivos, mas **não substitui a conferência humana**.

Antes de enviar o snapshot para um repositório público, confirme:

- [ ] o tema e o estudo da semana estão corretos;
- [ ] não há nomes, telefones, e-mails ou outros dados pessoais indevidos;
- [ ] os PDFs abaixo podem ser disponibilizados aos participantes;
- [ ] links externos abrem corretamente;
- [ ] o estudo preliminar está claramente identificado quando a Carta ainda não chegou;
- [ ] nenhuma credencial ou arquivo operacional foi adicionado manualmente ao snapshot.
